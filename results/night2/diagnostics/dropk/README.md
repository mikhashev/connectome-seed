# Drop-k ranking robustness

Task: Ranking robustness to item composition (drop-k), proposed by Ark 2026-09-15 06:47,
recorded in `docs/next-session-plan.md` Section 4. Pure CSV arithmetic, no GPU.

## Inputs (read-only, not modified)

- `../per_item_250008.csv` (primary rung)
- `../per_item_25212.csv` (context rung)

Each has columns `item, seed0, seed0prime, seed1, seed2, seed0prime_minus_seed0` for the
16 items (6 held-out scenes: `sequence_02_ambush_2`, `sequence_07_bamboo_1`,
`sequence_09_bandage_1`, `sequence_12_cave_4` [1 item], `sequence_13_market_2`,
`sequence_16_mountain_1`). seed0' (the replicate) is excluded from the ranking and
tracked separately as the twin-sign check.

## Command

```
python dropk.py
```

Run from this directory (`results/night2/diagnostics/dropk/`). Stdlib only
(`csv`, `itertools`, `json`, `statistics`, `collections`), no third-party
dependencies, no GPU.

## Outputs (written only into this directory)

- `dropk_results.json` — full machine-readable results for both rungs: full-set
  order, exhaustive drop-k (k=1,2,3) order distributions/fractions/pairwise-win
  fractions, all 16 drop-one items (k=1), the 10 most-different flipping triples
  (k=3, ranked by Kendall-tau distance from the full-set order), 6 scene-level
  drops, twin-sign robustness by k, per-item pairwise win counts (no aggregation),
  and leave-scene-in (6 single-scene orders).
- `dropk_summary.md` — human-readable digest of the same, auto-generated by the
  script's `write_summary()`.
- This `README.md`.

## What each analysis computes

1. Full-set order: rank seeds {0,1,2} by mean loss over all 16 items (lower =
   better).
2. Exhaustive drop-k, k=1 (16 subsets), k=2 (120), k=3 (560): for every way of
   removing k items, recompute the order on the remaining items. Reports:
   fraction of subsets that reproduce the full-set order exactly; the full
   distribution over all 6 possible orders; fraction where the full-set best
   seed is still best; pairwise win fractions (seed1 vs seed0, seed2 vs seed0,
   seed1 vs seed2) over subsets; for k=1 all 16 dropped-item outcomes; for k=3
   the 10 triples whose resulting order is furthest (by Kendall-tau distance)
   from the full-set order.
3. Scene-level drop: drop each of the 6 scenes entirely (all its items) and
   recompute the order — 6 subsets.
4. Twin-sign robustness: for every k=1,2,3 subset, the sign of the mean of
   `seed0prime_minus_seed0` over the remaining items; fraction positive.
5. Per-item pairwise counts (no aggregation): over the 16 items directly (not
   subset means), how many items each seed beats each other seed on.
6. Leave-scene-in: the order computed from each single scene's items alone (3
   items, or 1 for cave_4) — 6 orders.
